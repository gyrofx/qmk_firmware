Pico seen from the top (chip side), USB at the top. Pin 1 is top-left, next to the USB port. The GP numbers are also printed on the underside of the Pico, which helps if you mount it face-down.

PinGPIOWire

GP7, GP8 and GP28/27/26 stay free. No GND or 3V3 wire is needed for the matrix: USB powers the Pico.

How to solder each column

  1. Every switch has two pins. One already has the diode. The column wire goes to the other, free pin, with no diode.
  2. Column wires run across the photo, from left to right, and cross every row wire. Use insulated wire: strip a short window at each switch, or use enamelled wire and burn through at each joint.
  3. Follow the switches listed for each column, even where the line jumps. For example, C1 joins 1, LShift and Win, and skips the Tab and Caps rows.
  4. Run the end of each column wire to the Pico pin shown (see the Pico pinout above; GP7 and GP8 are skipped). The five row wires go to GP18–GP22 on the right-hand side.
  5. Check each column with a multimeter in continuity mode before moving on. It must not beep against any row wire.
